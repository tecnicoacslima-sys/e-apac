PRIVACIDADE E LGPD

Como o APAC digital cuida dos dados

Lei Geral de Proteção de Dados Pessoais (Lei nº 13.709/2018) · Última atualização: outubro de 2026

Em resumo:
  • O sistema é usado somente pelas equipes das unidades de saúde, com login e senha pessoais.
  • Cada unidade só enxerga os dados dela. Nem o administrador do sistema vê os pacientes de outra unidade.
  • Os dados servem só para o trabalho de regulação: gerar a APAC, controlar o protocolo e conferir cadastros.
  • Nada é vendido, divulgado ou usado para propaganda.

1. Para que serve

O APAC digital ajuda as unidades de saúde a preencher o Laudo para Solicitação/Autorização de Procedimento Ambulatorial (APAC), a controlar o protocolo de encaminhamentos e a conferir se os cadastros do paciente (Cartão SUS, CELK, documentos e comprovante de endereço) estão iguais.

2. Quais dados são tratados

  • Dos pacientes: nome, Cartão Nacional de Saúde (CNS), CPF, data de nascimento, sexo, nome da mãe, telefone, endereço e as informações de saúde necessárias ao encaminhamento (procedimento, CID, diagnóstico e observações do laudo).
  • Dos documentos enviados para leitura ou conferência (laudos, espelhos, documento de identidade e comprovante de endereço).
  • Dos profissionais: nome, Cartão SUS ou CPF e, quando cadastrados com autorização do profissional, a imagem do carimbo e da assinatura.
  • Dos usuários do sistema: nome, e-mail e o registro das ações principais (quem gerou, salvou ou cancelou).

3. Por que é permitido

O tratamento é feito para a execução de políticas públicas de saúde e para a tutela da saúde, pelas equipes do SUS, conforme os artigos 7º e 11 da LGPD. Os dados usados são apenas os necessários ao encaminhamento do paciente.

4. Quem pode ver

  • Somente pessoas convidadas pelo administrador, cada uma ligada a uma unidade.
  • A separação entre unidades é feita pelo próprio banco de dados (regra de segurança em cada tabela), e não só pela tela.
  • Quem escaneia o QR Code de uma APAC vê apenas a unidade, a data, o procedimento e as iniciais do paciente, e pode abrir o PDF daquela APAC, que é o mesmo documento que já está em papel com o paciente. Cada QR Code tem um código longo, impossível de adivinhar.

5. Onde os dados ficam

  • No Supabase (banco de dados e arquivos), em servidores na região de São Paulo, com conexão sempre criptografada (HTTPS).
  • A página do sistema fica no GitHub Pages, que guarda apenas o programa, nenhum dado de paciente.

6. Uso de inteligência artificial

Para ler laudos e conferir espelhos, o documento escolhido é enviado à IA Claude, da empresa Anthropic, pela sua interface de programação (API), com processamento fora do Brasil. Segundo os termos comerciais da Anthropic, os dados enviados pela API não são usados para treinar seus modelos. A chave de acesso fica guardada no servidor, nunca no navegador. A IA sugere os dados; quem confere e decide é sempre o profissional da unidade.

7. Por quanto tempo

Os registros ficam guardados enquanto forem necessários ao acompanhamento dos encaminhamentos e às obrigações da Secretaria Municipal de Saúde. O administrador pode apagar os dados de uma unidade quando ela deixar de usar o sistema. Cada unidade pode baixar uma cópia de segurança dos próprios dados.

8. Direitos do paciente

O paciente pode pedir para saber quais dados seus estão registrados, corrigir dados errados ou tirar dúvidas. O pedido deve ser feito na unidade de saúde onde é atendido ou à Secretaria Municipal de Saúde, que é a responsável pelos dados.

9. Cuidados de quem usa

  • Não compartilhe sua senha. Ao sair do computador, clique em Sair.
  • Guarde as cópias de segurança e os PDFs baixados em local protegido e não os envie para quem não precisa.
  • Use o carimbo e a assinatura de um profissional somente com a autorização dele.

Este aviso descreve como o sistema funciona. Ele não substitui as normas e a orientação do encarregado de proteção de dados (DPO) da Secretaria Municipal de Saúde.
